URL: http://localhost:3000/api/books/:id  
Purpose: Update a book by ID  
Body Parameters: { "title": "", "author": "", "price": "", "genre": "" }

Method: DELETE  
URL: http://localhost:3000/api/books/:id  
Purpose: Delete a book by ID  
Body Parameters: None
